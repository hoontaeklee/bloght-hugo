dos2unix#

윈도우에서 쓰던 deploy.sh는 윈도우 스타일의 bash 파일이다. 이걸 우분투에서 실행하면

$’\r’: command not found

와 같은 에러를 볼 수 있다. 저 개행문자를 우분투에서는 이해 못하기 때문.

sudo apt-get install dos2unix
dos2unix [file]

를 실행해서 우분투 스타일로 바꾼 후 실행하자.

How do I fix "$'\r': command not found" errors running Bash scripts in WSL? - Ask Ubuntu

git 계정 설정#

새로운 노트북에서 내 git repository를 사용하기 위해서는

내가 누구인지 다시 한 번 선언(?)해야 하나보다.

git config --global user.email myGithubEmailAddress
git config --global user.name myGithubUserName
